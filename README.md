# Oil & Gas Production Dashboard

An interactive dashboard for monitoring oil and gas production data using Streamlit.

## Features

- Real-time monitoring of oil and gas production
- Interactive visualizations using Plotly
- Production trends and analytics
- Anomaly detection capabilities

## Setup

1. Clone the repository
2. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```
3. Run the dashboard:
   ```bash
   streamlit run app.py
   ```
